# Promptlane

The complete AI web development workshop site, built with React, Vite, TypeScript, and Tailwind CSS.

Use Node 20.19+ or 22.12+.

```sh
npm ci
npm run dev
```

To validate and preview the production build:

```sh
npm run build
npm run preview
```

Sections are in `src/components`. Shared buttons are in `src/components/ui/Button.tsx`. Images, video, fonts, and icons are bundled from `src/assets`.
